= Parameters

The parent key for all of the following parameters is `{{ cookiecutter.parameter_key }}`.

== `namespace`

[horizontal]
type:: string
default:: `syn-{{ cookiecutter.slug }}`

The namespace in which to deploy this component.

== `createNamespace`

[horizontal]
type:: boolean
default:: `false`

Whether to create the namespace. If this is set to `false`, the namespace isn't created.

== `namespaceLabels`

[horizontal]
type:: dict
default:: `{}`

Labels which are added to the created namespace. This parameter is only used if `createNamespace` is `true`.
The namespace also gets the automatically applied labels `component: <slug>` and `instance: <instance>`; values set in `namespaceLabels` take precedence over these defaults on key conflict.

== `namespaceAnnotations`

[horizontal]
type:: dict
default:: `{}`

Annotations which are added to the created namespace. This parameter is only used if `createNamespace` is `true`.
The namespace also gets the automatically applied annotation `syn.tools/source: <component GitHub URL>`; values set in `namespaceAnnotations` take precedence on key conflict.

== Example

[source,yaml]
----
namespace: example-namespace
createNamespace: true
namespaceLabels:
  example.com/label: value
namespaceAnnotations:
  example.com/annotation: value
----
