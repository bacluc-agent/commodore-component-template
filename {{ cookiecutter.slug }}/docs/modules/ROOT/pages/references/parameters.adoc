= Parameters

The parent key for all of the following parameters is `{{ cookiecutter.parameter_key }}`.

== `namespace`

[horizontal]
type:: string
default:: `syn-{{ cookiecutter.slug }}`

The namespace in which to deploy this component.


== Example

[source,yaml]
----
namespace: example-namespace
----

== `createNamespace`

[horizontal]
type:: boolean
default:: `true`

Whether to create the namespace. If this is set to `false`, the namespace isn't created.


== Example

[source,yaml]
----
createNamespace: true
----

== `namespaceLabels`

[horizontal]
type:: dict
default:: `{}`

Labels which are added to the created namespace. This parameter is only used if `createNamespace` is `true`.


== Example

[source,yaml]
----
namespaceLabels:
  foo: bar
----

== `namespaceAnnotations`

[horizontal]
type:: dict
default:: `{}`

Annotations which are added to the created namespace. This parameter is only used if `createNamespace` is `true`.


== Example

[source,yaml]
----
namespaceAnnotations:
  foo: bar
----
